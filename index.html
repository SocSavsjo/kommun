Dashboard Jönköpings län

Livehämtade nyckeltal för länets kommuner med jämförelser mot Höglandet, Jönköpings län och riket.

Vald huvudkommun: Sävsjö
Klar att ladda

Källa: Kolada API v3. Höglandet beräknas i sidan av kommunvärdena. Jönköpings län hämtas som Kolada-värde där det finns, annars beräknas det live från länets kommuner. Riket hämtas som livevärde från Kolada.
